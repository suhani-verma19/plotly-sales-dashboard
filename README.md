# Interactive Sales & Profit Dashboard

An interactive sales dashboard built with Python, Pandas, and Plotly.

**Note:** The data in this project is sample data created for learning purposes.

![Dashboard](Screenshot%202026-11-05%20124935.png)

## Features
- Monthly sales, profit, and orders analysis
- Profit margin and average order value
- Interactive dropdown to switch between Sales and Profit
- KPI cards for key business metrics

## Tools Used
- Python
- Pandas
- Plotly
- Google Colab

## How to Run
1. Open `Plotly_Interactive_Sales_Dashboard_Github.ipynb` in Google Colab.
2. Click **Runtime → Run all**.
